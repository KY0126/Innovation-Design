# 使用者情境（角色卡）

| 編號 | 角色 | 目標 | 卡關點 | 主要畫面 |
|---|---|---|---|---|
| P1 | 陳小姐（付費子女，三明治世代） | 不同住也能顧好媽媽家 | 無法親臨、多工班分批場勘、型錄找不到合適商品 | 揪居家 App：居家評估、方案、結帳、揪心願 |
| P2 | 林媽媽（獨居高雄三民區的長輩） | 夜裡起床上廁所不跌倒、不被監看 | 不想裝鏡頭、看不懂小字 | 長輩大字確認、「我很好」 |
| P3 | 小安（在高雄讀大學的孫女，校園大使） | 陪阿嬤做居家觀察 | 不知道怎麼開口、怎麼量 | AR 掃描、校園大使任務 |
| P4 | 王小明顧問（取得居安規劃認證的門市人員） | 一次講清楚方案、產出正式報價 | 資訊分散、長輩要本人同意 | App（今日行程、案件）＋電腦版報價 |

| P6 | 門市主管與總部營運 | 看試點數字、審揪心願、維護常見問題 | 資料不即時、人力負荷 | 企業管理端（電腦版） |
| P7 | 五子登科 LINE 好友 | 快速找到功能、收到通知 | 不想下載新 App | 分頁圖文選單「揪居家｜五子登科好康」、自動回應 |

## 撰寫規則

- 新功能或 User Story 要標出對應的角色編號（P1–P7）與卡關點。
