## 規則

- 改了被引用的 JS 檔，要同步加大引用處的 `?v=` 版本號（例如 `wish.js` 裡的 `cad3d.js?v=`、`app.html` 裡的 `wish.js?v=`）。
- 分支名用 `stage2-…`（遠端已有 `stage2` 分支，不能用 `stage2/…`）。
- 暫時的截圖頁、比對用舊檔用底線開頭（例如 `_shot3d.html`），不提交。
