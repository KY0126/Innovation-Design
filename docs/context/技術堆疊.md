# 技術堆疊

> 原型（Demo 版）是不需要伺服器的靜態網站；LINE 選單與之後的實用版才用到雲端。2026/11/26 確認。

| 編號 | 項目 | 用什麼 | 為什麼／限制 |
|---|---|---|---|
| T1 | 網站託管 | GitHub Pages（main 分支） | 免費、合併即上線；只能放靜態檔 |
| T2 | 畫面 | 純 HTML＋CSS＋JavaScript，無框架 | 接手門檻低；快取靠檔名後的 `?v=` 版本號 |
| T3 | 模擬後端 | sql.js（瀏覽器內的 SQLite），`store.js`～`store3.js` 經 `/api` 讀寫 | 可實際登入與即時同步展示；資料只存在本機瀏覽器 |
| T4 | 圖面與 3D | 自寫 SVG 施工圖（`cad.js`）、three.js r169（`cad3d.js`） | 業界畫法；3D 在無顯示卡機器用軟體算圖 |
| T5 | AR 量測 | Android WebXR；iPhone 用內建測距儀後手動輸入 | iPhone 網頁不支援 WebXR |
| T6 | 測試 | Playwright（電腦版＋手機版）＋GitHub Actions；Lint、單元等見測試規範 | 現有系統測試 111 項 |
| T7 | LINE 官方帳號 | OA Manager（歡迎訊息、關鍵字回應）＋Messaging API（分頁圖文選單） | Webhook 關閉；一開 Webhook，關鍵字回應會失效 |
| T8 | 雲端程式 | Supabase Edge Function `line-richmenu-setup` | 金鑰只在請求中使用；Supabase 專案和其他課程共用 |
| T9 | 計畫書 | Markdown 經 `build.js`（docx 套件）轉 Word，再用 LibreOffice 轉 PDF | 標楷體 12 級；頁數以 Word 為準 |
| T10 | 示意圖 | Claude Design 畫布 | 改正式檔前的改之前／改之後 |

## 實用版（規劃中，2026/12/11 後）

- 資料：Supabase（PostgreSQL＋列級權限），資料表與觸發器放 `supabase/`。
- 登入：LINE 登入或 Email。
- 入口：`/live/app`、`/live/admin`，與 Demo 版共用 `jiujujia/*.js`，用設定切換資料來源。
