# GLOSSARY — 揪居家用語表

所有使用者看得到的文字（按鈕、提示、表單驗證、通知、測試資料的顯示名稱）一律照「使用」欄。
`npm run check:glossary` 會讀取下面兩張表的「禁用」欄，在程式碼中找到就報錯。禁用欄多個詞用「、」分隔，留空代表不檢查。
