# [門市端] 生活顧問查看已送出的評估

## User Story
身為 **生活顧問（門市人員）**，
我想要 **看到我的門市收到的居家評估清單與內容**，
以便 **安排報價與到府服務**。

## 領域
- [ ] customer　- [x] store

## 驗收條件（Given-When-Then）
**正常情境**
- Given 我以生活顧問登入，When 開啟「待處理評估」，Then 依送出時間新到舊列出本門市已送出的評估，每筆顯示長輩稱呼、地址、紅燈數、送出時間。
- Given 我點開一筆，When 檢視內容，Then 依區域看到每個項目、尺寸、材質、燈號；有同意上傳的照片才顯示照片。

**輸入邊界**
- Given 本門市沒有任何已送出評估，When 開啟清單，Then 顯示「目前沒有待處理的評估」。

**例外與錯誤處理**
- Given 評估仍是草稿，When 我查詢，Then 看不到（安全規則拒絕）。
- Given 評估屬於其他門市，When 我嘗試開啟網址，Then 被拒絕並顯示「沒有權限」。

## 不在本 issue 範圍
- 指派給特定顧問、轉介其他門市。
