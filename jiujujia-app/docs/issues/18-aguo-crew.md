# [AI顧問阿國] 派工推薦：全國電子技師與協力工班

## User Story
身為 **生活顧問**，
我想要 **長輩同意後，阿國依工種與空檔推薦技師或協力工班**，
以便 **快速排出合適的人力**。

## 領域
- [ ] customer　- [x] store　- [x] 阿國（能力 `crew_recommend`）

## 驗收條件（Given-When-Then）
**正常情境**
- Given 報價已由長輩本人同意，品項含門檻（泥作）與感應燈（安裝），When 呼叫 `crew_recommend`（日期、上午／下午），Then 泥作推薦協力工班、安裝推薦全國電子技師，每位附推薦原因。
- Given 推薦清單，When 顧問選定並建立派工單，Then 走一般派工流程（阿國不建立派工單）。

**輸入邊界**
- Given 該時段沒有合適人員，When 推薦，Then 顯示「這個時段沒有合適人員」並給最近的可用時段。

**例外與錯誤處理**
- Given 報價尚未被長輩同意，When 呼叫，Then 拒絕。
- Given 日期格式錯誤，When 呼叫 MCP 工具 `find_available_crews`，Then 回傳型別錯誤。
