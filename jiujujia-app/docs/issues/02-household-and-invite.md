# [顧客端] 建立長輩家與邀請長輩加入

## User Story
身為 **陳小姐（家人）**，
我想要 **建立林媽媽的「長輩家」資料，並用邀請碼讓林媽媽本人加入**，
以便 **之後的評估、報價都綁在這個家，而且只有林媽媽本人能同意施工**。

## 領域
- [x] customer　- [ ] store

## 驗收條件（Given-When-Then）
**正常情境**
- Given 我以家人身分登入，When 我填寫長輩稱呼、地址、選擇服務門市並按「建立長輩家」，Then 系統建立長輩家，並顯示 6 碼邀請碼。
- Given 長輩家已建立，When 我回到首頁，Then 看得到這個長輩家的名稱、地址、門市與「長輩尚未加入」狀態。
- Given 林媽媽以長輩身分登入，When 她輸入正確的邀請碼並按「加入」，Then 她成為該長輩家的長輩，陳小姐的首頁狀態變成「長輩已加入」。

**輸入邊界**
- Given 我在建立表單，When 長輩稱呼或地址空白，Then 顯示「請填寫長輩稱呼／地址」且不送出。
- Given 邀請碼輸入框，When 輸入不是 6 碼，Then 不送出並提示「邀請碼為 6 碼」。邀請碼不分大小寫，且不含容易看錯的 0、O、1、I。

**例外與錯誤處理**
- Given 邀請碼不存在，When 長輩送出，Then 顯示「找不到這個邀請碼，請向家人確認」。
- Given 長輩家已有長輩加入，When 另一個長輩帳號輸入同一邀請碼，Then 顯示「這個長輩家已有長輩加入」並拒絕。
- Given 我以家人身分，When 我嘗試用邀請碼加入，Then 系統提示「邀請碼只供長輩本人使用」。
- Given 我不是這個長輩家的家人或長輩，When 我嘗試讀取它的資料，Then 被安全規則拒絕。

## 不在本 issue 範圍
- 邀請其他兄弟姊妹（家人）共同管理、分攤費用。
- 一個家人管理多個長輩家（MVP 先只顯示第一個）。
