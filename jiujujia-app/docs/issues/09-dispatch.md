# [門市端] 長輩同意後派工給技師或協力工班

## User Story
身為 **生活顧問**，
我想要 **在長輩同意後，選擇時段並指派全國電子技師或協力工班**，
以便 **安排到府施工**。

## 領域
- [ ] customer　- [x] store

## 驗收條件（Given-When-Then）
**正常情境**
- Given 報價狀態為「長輩已同意」，When 我選擇日期、上午或下午，並指派至少一位人員，Then 建立派工單，狀態為「已排定」，家人看得到施工時間。
- Given 品項含泥作或木作（例：門檻、防滑地板），When 指派，Then 系統提示應指派協力工班；設備安裝提示指派全國電子技師。

**輸入邊界**
- Given 選擇的日期早於今天，When 送出，Then 顯示錯誤。
- Given 沒有指派任何人員，When 送出，Then 無法送出。

**例外與錯誤處理**
- Given 報價尚未被長輩同意，When 我開啟派工，Then 按鈕無法使用並顯示「需長輩本人同意後才能派工」；直接寫入資料也被安全規則拒絕。
- Given 指派的人員該時段已有工作，When 送出，Then 提示時段衝突。
