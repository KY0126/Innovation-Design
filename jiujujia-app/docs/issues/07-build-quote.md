# [門市端] 整合報價並送給長輩

## User Story
身為 **生活顧問**，
我想要 **依評估項目建立一張報價（設備、工程、關懷月費）並送出**，
以便 **林媽媽本人確認是否施工**。

## 領域
- [ ] customer　- [x] store（交接合約 `QuoteSent`）

## 驗收條件（Given-When-Then）
**正常情境**
- Given 一筆已送出的評估，When 我新增品項（名稱、單位：坪／公尺／組／月、數量、單價），Then 系統即時計算小計與總額，金額以整數新台幣顯示。
- Given 報價草稿完成，When 我按「送出報價」，Then 報價狀態變為「已送出」，家人與長輩都看得到。
- Given 報價含關懷月費，When 顯示，Then 一次付清的金額與每月費用分開列出。

**輸入邊界**
- Given 單價或數量，When 輸入小數金額、負數或 0，Then 顯示錯誤；數量允許到小數一位（例：3.5 坪），金額一律四捨五入為整數元。
- Given 報價沒有任何品項，When 按送出，Then 無法送出。

**例外與錯誤處理**
- Given 報價已被長輩同意，When 我嘗試修改，Then 被拒絕，需另開新報價。
- Given 我嘗試直接把狀態改成「長輩已同意」，Then 被安全規則拒絕。
