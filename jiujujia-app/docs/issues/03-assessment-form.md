# [顧客端] 填寫居家評估（手動輸入尺寸）

## User Story
身為 **陳小姐（家人）**，
我想要 **依區域記錄林媽媽家的危險點、量到的尺寸與材質**，
以便 **系統判斷風險，生活顧問也能依實際尺寸報價**。

## 領域
- [x] customer　- [ ] store

## 驗收條件（Given-When-Then）
**正常情境**
- Given 長輩家已建立，When 我選擇區域（浴室、臥室、走道、客廳、廚房、玄關）並新增一個項目（危險點類型、尺寸公分、材質），Then 項目出現在該區域清單，並自動存成草稿。
- Given 草稿已有項目，When 我離開後再回來，Then 草稿內容仍在。

**輸入邊界**
- Given 需要尺寸的危險點（例：門檻高度、走道寬度），When 尺寸空白、為負數或超過 500 公分，Then 顯示錯誤且不儲存該項目。
- Given 我勾選「上傳照片」，When 我沒有勾選「同意上傳照片」，Then 不允許選擇照片。

**例外與錯誤處理**
- Given 網路中斷，When 我新增項目，Then 顯示「尚未儲存，連線後會自動重試」。
- Given 我是長輩本人，When 我開啟評估頁，Then 可以查看但預設不顯示編輯按鈕（由家人填寫）。
