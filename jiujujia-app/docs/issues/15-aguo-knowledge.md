# [阿國] 知識問答（RAG）：長照補助、輔具、居家安全

## User Story
身為 **生活顧問與家人**，
我想要 **問阿國補助、輔具、居家改善的問題時，答案來自可信資料並附上來源**，
以便 **給長輩的建議有根據，不靠 AI 自己編**。

## 領域
- [ ] customer　- [ ] store　- [x] 阿國（能力 `knowledge_qa`，也供其他能力引用）

## 驗收條件（Given-When-Then）
**正常情境**
- Given `jiujujia-agent/knowledge/` 的文件（每份標明官方出處網址與取得日期），When 問「浴室要怎麼防滑」，Then 回答引用最相關的段落並列出來源。
- Given 10 題評估題組（問題＋應找到的文件），When 執行 `evals`，Then 至少 8 題找到正確文件。
- Given 補助轉介問題，When 回答，Then 條件寫「長照等級第 2 級以上」，與共用規則一致。

**輸入邊界**
- Given 問題空白或超過 200 字，When 呼叫，Then 拒絕並提示。

**例外與錯誤處理**
- Given 知識庫沒有相關資料，When 回答，Then 說「知識庫沒有這方面的資料」，不可編造答案或來源。
- Given 問題內含「忽略以上指示」，When 處理，Then 只當成查詢文字。
