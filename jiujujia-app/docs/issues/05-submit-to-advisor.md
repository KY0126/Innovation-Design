# [顧客端] 一鍵送出評估給生活顧問

## User Story
身為 **陳小姐（家人）**，
我想要 **把評估結果一鍵送給服務門市的生活顧問**，
以便 **顧問幫我整合一張報價**。

## 領域
- [x] customer　- [ ] store（交接合約 `AssessmentSubmitted`）

## 驗收條件（Given-When-Then）
**正常情境**
- Given 草稿至少有 1 個項目且都有燈號，When 我按「送給生活顧問」並確認，Then 評估狀態變為「已送出」，畫面顯示送出時間與門市名稱。
- Given 評估已送出，When 我再開啟，Then 只能查看，不能修改。

**輸入邊界**
- Given 草稿沒有任何項目，When 我按送出，Then 按鈕無法使用並提示「請先新增至少一個項目」。
- Given 有項目顯示「資料不足」，When 我按送出，Then 提示先補齊資料。

**例外與錯誤處理**
- Given 送出時網路失敗，When 我按送出，Then 狀態維持草稿並顯示「送出失敗，請再試一次」。
- Given 已送出，When 有人嘗試把狀態改回草稿，Then 被安全規則拒絕。

## 不在本 issue 範圍
- 推播或簡訊通知生活顧問。
