# [阿國] 評估建議：燈號、改善方案、安裝方式

## User Story
身為 **陳小姐（家人）**，
我想要 **AR 量測（目前為手動輸入尺寸）後，阿國依尺寸和材質整理出每個項目的燈號、改善方案與推薦的安裝方式**，
以便 **先了解要改什麼，再一鍵送給生活顧問**。

## 領域
- [x] customer　- [ ] store　- [x] 阿國（能力 `assess`）

## 驗收條件（Given-When-Then）
**正常情境**
- Given 一份評估（區域可複選、每項有尺寸與材質），When 呼叫 `assess`，Then 每項回傳燈號（與 `risk-rules.json` 一致）、改善方案、安裝方式與來源，10 秒內完成。
- Given 揪夜安場域，When 評估夜間動線，Then 建議依場域整組配好，預設不裝鏡頭。

**輸入邊界**
- Given 傳給 LLM 的內容，When 自動檢查，Then 只有區域、危險點、尺寸、材質，沒有姓名、地址、照片。
- Given 全部綠燈，When 呼叫，Then 回傳「目前沒有需要改善的項目」，不硬給建議。

**例外與錯誤處理**
- Given 阿國回傳的燈號與規則檔不一致，When 程式檢查，Then 退回重做；仍不一致就用規則結果並標示備援。
- Given LLM 逾時，When 呼叫，Then 回傳規則備援的基本建議。
