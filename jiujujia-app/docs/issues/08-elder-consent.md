# [顧客端] 長輩本人同意報價

## User Story
身為 **林媽媽（長輩）**，
我想要 **用大字清楚看到報價內容，並由我本人按下同意或不同意**，
以便 **家裡要不要施工由我自己決定**。

## 領域
- [x] customer　- [ ] store（交接合約 `ElderConsent`）

## 驗收條件（Given-When-Then）
**正常情境**
- Given 報價已送出且我是這個長輩家的長輩，When 我開啟報價，Then 以大字顯示每個品項、總額與每月費用。
- Given 我看完報價，When 我按「我同意施工」並再次確認，Then 報價狀態變為「長輩已同意」，記錄同意人與時間，家人與生活顧問都看得到。
- Given 我不想施工，When 我按「先不要」，Then 報價狀態變為「長輩未同意」。

**輸入邊界**
- Given 報價不是「已送出」狀態，When 我開啟，Then 不顯示同意按鈕。

**例外與錯誤處理**
- Given 我是家人（陳小姐），When 我開啟報價，Then 看得到內容，但只顯示「需由長輩本人同意」，沒有同意按鈕。
- Given 家人或生活顧問直接寫入同意欄位，Then 被安全規則拒絕。
- Given 長輩家還沒有長輩加入，When 家人開啟報價，Then 提示「請先邀請長輩加入，才能同意報價」。
