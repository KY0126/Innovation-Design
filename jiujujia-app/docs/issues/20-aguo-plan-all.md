# [AI顧問阿國] 一鍵整理：多代理人協作（評估 → 報價 → 派工）

## User Story
身為 **生活顧問**，
我想要 **一次請阿國從評估結果一路整理出改善建議、報價草稿、說明話術與人力推薦**，
以便 **到府前就有完整的準備**。

## 領域
- [ ] customer　- [x] store　- [x] 阿國（能力 `plan_all`）

## 驗收條件（Given-When-Then）
**正常情境**
- Given 一份已送出的評估，When 呼叫 `plan_all`，Then 協調者依序交給評估、報價、派工三個 agent（沿用 v1.3 的驗證 Agent 把關），結果分區顯示並標示由哪個 agent 產生。
- Given 執行過程，When 查看紀錄，Then 看得到每個 agent 呼叫了哪些 MCP 工具與耗時。

**輸入邊界**
- Given 總時間超過 30 秒，When 執行，Then 已完成的部分先回傳，未完成的標示「逾時」。

**例外與錯誤處理**
- Given 其中一個 agent 失敗，When 協調，Then 其他結果照常回傳，失敗的那區用規則備援。
- Given 任何 agent，When 執行，Then 都不能寫入報價、同意或派工單。
