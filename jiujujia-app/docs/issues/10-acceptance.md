# [顧客端] 施工後逐區驗收

## User Story
身為 **林媽媽（長輩）或陳小姐（家人）**，
我想要 **施工完成後逐區確認是否滿意**，
以便 **有問題的地方可以請門市回來處理**。

## 領域
- [x] customer　- [ ] store（交接合約 `WorkOrderAccepted`）

## 驗收條件（Given-When-Then）
**正常情境**
- Given 派工單狀態為「已完成」，When 我逐區按「沒問題」或「需要處理」，Then 系統記錄每區結果。
- Given 所有區域都「沒問題」，When 送出驗收，Then 派工單狀態變為「已驗收」。

**輸入邊界**
- Given 選「需要處理」，When 備註空白，Then 要求填寫說明（最多 200 字）。

**例外與錯誤處理**
- Given 派工單尚未完成，When 開啟驗收，Then 不顯示驗收按鈕。
- Given 家人或長輩嘗試修改派工單的人員或時段，Then 被安全規則拒絕（只能寫驗收欄位）。

## 不在本 issue 範圍
- 售後服務排程、一年後主動保養提醒。
