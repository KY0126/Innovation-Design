# 揪居家開發時程｜AI顧問阿國一個多用

揪居家所有 AI、LLM、MCP、Agent 相關的功能都是同一個「AI顧問阿國」（簡稱阿國）：**一個核心、一套 API、三個使用方**。

| 使用方 | 怎麼用阿國 | 什麼時候 |
|---|---|---|
| 二階提案新版原型 `/v2/`（stage2 分支） | 接法 C：平常讀阿國預先產生的結果，企業 Demo 時切換即時連線 | 11/18～12/16 |
| 軟工課 MVP `jiujujia-app/` | 網站伺服器呼叫阿國 API，結果標示「AI顧問阿國建議」，由人決定是否採用 | 12/17 起 |
| AI 語言模型系統整合課 | 用同一個阿國做作業、評估題組與期末 Demo | 全程 |

## 放在哪裡

```
Innovation-Design/
├── （原型：*.html、jiujujia/、demo/、e2e/ 都不動；二階新版在 stage2 分支的 /v2/）
├── jiujujia-app/            軟工課 MVP（Next.js + Firebase）
│   ├── app/api/aguo/            只有這裡會呼叫阿國（伺服器端，先驗證登入身分）
│   └── lib/shared/data/         紅黃綠燈規則、報價品項、場域：網站、阿國、/v2/ 共用的唯一來源
└── jiujujia-agent/          阿國（Python + MCP，以二階 v1.3 為基底）
    ├── aguo/capabilities/       7 項能力：評估建議、報價草稿、說明話術、派工推薦、揪心願分類、知識問答、一鍵整理
    ├── aguo/pipeline.py         每項能力都走同一條檢查：程式檢查 → 驗證 Agent → 退回重做 → 規則備援
    ├── servers/                 MCP server：規則、知識庫、人力時段
    └── knowledge/ evals/ tests/
```

為什麼這樣放：

- **一個核心**：新的 AI 功能只能加成阿國的一項「能力」，不能另外寫一支程式，避免二階、MVP、課堂作業各做一套、結果不一致。
- **同一份規則**：紅黃綠燈、報價品項、五場域、二階新規則（異常先問長輩兩次、每區可複選、補助條件長照等級第 2 級以上）都放在共用資料檔，三方讀同一份。
- **阿國只提建議**：只收到最少的資料（不含姓名、地址、照片），報價、長輩同意、派工一律由人決定。
