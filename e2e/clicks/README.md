# 點擊數基準（自動腳本版）

量測方式：Playwright 用每個介面版本的**最短點擊路徑**實際點一次（`paths.js`），記錄點擊數；另外量各身分落地頁「看得到、可以點」的元素數與頁面長度（幾個螢幕高）。手機 390×844、電腦 1440×900；不含右下角展示用按鈕與 App 底部選單。

這是腳本量的下限，不代表真人實際的點擊數與完成時間；真人測試（3～5 位同學、同樣任務）之後補上。

重跑：`node e2e/clicks/measure.js after`（改版前的數字用 commit 63dc7d6 量測）。
