# 測試修正流程

1. **重現**：本機跑同一個測試（`npx playwright test -g "<標題>" --project=<專案>` 或 `node --test tests/unit/<檔>`）。
2. **分類**：
   - 程式錯：修程式。
   - 測試過時（例如改字沒改測試）：改測試，PR 寫明原因。
   - 偶發失敗：記進 `tests/flaky.md`（日期、測試、現象），限期修好。
3. **先補一個會失敗的測試**，再修；修好後測試留下。
4. **全部重跑**：`tests/` 的 `npm run check`、`e2e/` 的 `npm test`，都過才推。
5. **不能做**：刪測試、放寬檢查條件、更新基準線、把 CI 改成失敗也算過；一定要做時先問使用者。
6. **CI 失敗時**：先看 Actions 上自動標出的失敗項目，再用上傳的報告（e2e-report）看截圖與 trace。
