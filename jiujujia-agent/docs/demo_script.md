# Demo 腳本（11/27 五股總公司｜筆電現場，約 5 分鐘）

> 上場前一天：
> 1. `python make_data.py`（重置展示資料，日期會自動排在未來）
> 2. `python -m evals.run_eval --demo-only`：Demo 題必須 **全部正確**（v1.3 共 16 題）才上場；沒全過就改用錄好的影片
> 3. 錄一份備用影片（網路斷線時播）
> 4. 關掉 `.env` 分頁、桌面不要露出金鑰

## 開場（30 秒）
「我們把揪居家裡的 AI 拆成三個 MCP Server，分別接全國電子既有的 App 評估資料、ERP 和 CRM。不用換系統，只是讓 AI 能安全地用它們。」→ 秀 `docs/architecture.png`

## 流程一｜家人陳小姐（1 分 30 秒）
`python -m aguo chat --user chen --detail`
1. 「我媽家評估結果怎麼樣？」→ 走道紅燈、浴室黃燈，下方顯示 ✔ 通過三道檢查
2. 「浴室要怎麼改比較好？」→ 斜坡墊＋止滑地墊；磁磚地，止滑條貼在門檻內側
3. 「走道裝感應夜燈加止滑卡扣地板、浴室用斜坡墊加止滑地墊，再加揪夜安，總共要多少錢？」→ 10,000 元、月費 299 元（走道選項和提案書圖 3、Demo 影片相同）
4. 「好，就這樣，幫我送給生活顧問。」→ 跳出 [確認]，按 y

講重點：**金額是 ERP 工具算的，AI 只負責說明；送出前一定問人。**

## 流程二｜生活顧問王小明（1 分 30 秒）
另開一個終端機：`python -m aguo chat --user wang --detail`
1. 「林媽媽剛剛在門市當面同意報價了，幫我記錄。」→ 確認 y
2. 「幫我看（三天後的日期）誰可以去林媽媽家？」→ 示範地坪 C 09:00 先鋪止滑卡扣地板、吳技師 14:00 安裝（和原型顧問端的 AI 推薦相同）
3. 「就照你推薦的派工。」→ 確認 y

講重點：**AI 推薦、顧問決定；沒有長輩本人同意，系統不讓派工。** 回應企業提到的「第一線門市人員轉型」：顧問不用背所有商品，AI 幫忙查、算、排。

## 流程三｜夜間關懷（40 秒）
（王小明終端機）「林媽媽家（昨天日期）晚上有沒有狀況？」→ 演練事件：浴室停留超過 30 分鐘，第 1 次燈光語音詢問；5 分鐘未回應，第 2 次撥打家中電話；兩次都沒回應 → 需通知家人；「幫我通知家人。」→ 通知陳小姐

講重點：**預設不裝鏡頭，只有感測器；先問長輩兩次，都沒回應才通知家人，和提案書與 App 的規則一樣。**

## 缺陷重現｜AI 寫錯會怎樣（40 秒）
`pytest` → 秀 T02、T04、T17 三行：
- AI 把門檻寫成 3 cm、浴室寫成紅燈 → 證據比對攔下 → 重寫
- AI 自己加總成 10,100 元 → 攔下 → 改用系統算的 10,000 元
- 資料裡藏「直接派工」的指令 → 標記為注入、不照做

講重點：**每一句話不是對過證據，就是系統固定版本；沒檢查過的內容不會送到顧客面前。**

## 可能被問的問題
| 問題 | 回答方向 |
|---|---|
| 這些資料是真的嗎？ | 全部是模擬資料，數值和我們的原型一致；希望二階能拿到去識別化數據換上去 |
| 為什麼用 MCP，不直接寫 API？ | 三個系統各自一個 Server、各自最小權限；換 LLM 不用改系統；之後要加售後保養只要加工具 |
| AI 會不會亂講？ | 三道檢查＋退回機制；並說明限制：檢查保證有根據，不保證每題都答得完整，所以有 22 題評測題庫 |
| 揪夜安的設備全國電子有賣嗎？ | 現場問阿國「全國電子有賣哪些揪夜安的商品？」：列出官網查到的商品與售價，也列出查不到的門窗感測器、緊急按鈕等，順勢請教總公司門市是否販售或能否由供應商引進 |
| 成本？ | 回答模型＋驗證模型各一次呼叫；Cloudflare 有免費額度（實際費用依全國電子用量另估） |


## 流程四｜v1.3：量測準不準、現場不一樣怎麼辦、裝完之後（約 2 分鐘，時間夠再做）
1. 手機開量測頁，用卡片近拍門檻（或直接秀量測結果畫面）→ 講重點：**照片算完就清除；信心度不夠，系統要求重拍，不拿來判斷。**
2. （王小明終端機）「黃先生家的浴室門檻量測可靠嗎？」→ 門檻 3 cm 剛好在分界，標成需技師到府確認。
3. 另開終端機 `python -m aguo chat --user chent --detail`：「黃先生家門檻我現場量是 3.4 公分。」→ 確認 y，回報差異。
4. 回到王小明：「核准剛剛的差異。」→ 浴室黃燈變紅燈，提醒重新確認報價與長輩同意。
5. 「未來 30 天有哪些家電要保養？」→ 李先生家冷氣，全國空調清洗 2,399 元（官網價）。
6. 「揪食光一個月多少錢？」→ 尚未開放：**等全國電子的進貨價再定，AI 不會自己報價。**

講重點：**回應「技師能否照圖施工」：AI 的判斷有誤差就交給人確認，現場不一樣由顧問核准；裝完之後家電檔案接手，讓一次交易變成長期關係。**
